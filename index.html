1. Работа игры и сохранения

Игра бесплатная, не требует регистрации и не содержит встроенных покупок. Все заказы и игровые ресурсы находятся в приложении. Очистка данных или удаление приложения может удалить прогресс. Облако и SDK Яндекс Игр не используются.

2. Реклама и выбор пользователя

В приложение входит Yandex Mobile Ads SDK 8.6.0 и его зависимость AppMetrica 8.6.0. Явный вызов инициализации SDK и загрузка рекламы приложением выполняются после разрешения сетевой рекламы. При первом запуске можно разрешить контекстную рекламу или выбрать игру без сетевой рекламы. Отказ не ограничивает заказы, оборудование и основную награду. Выбор меняется через паузу → Android «Назад» → «Реклама». Кнопка «Подробнее» в диалоге рекламы открывает политику. Если SDK уже запускался, отказ прекращает новые рекламные запросы приложения; для завершения ранее начатой сетевой работы можно закрыть приложение.

При разрешённой рекламе SDK может передавать сетевой адрес, технические сведения об устройстве и приложении (например, модель, ОС, язык, параметры экрана и версии приложения/SDK), собственные идентификаторы установки и события загрузки, показа и закрытия рекламы. IP-адрес может позволять определить приблизительный регион. Эти сведения обрабатываются Яндексом для доставки, учёта и защиты рекламы. Персонализация, геолокация и дополнительная рекламная аналитика отключены приложением до инициализации SDK; включён ограниченный возрастной режим. Разрешение Google AD_ID удалено из манифеста. Это не означает отсутствия технических идентификаторов или сетевых данных. Разработчик не отправляет собственные сетевые события игровой аналитики. Аккаунта, чата, платежей и облачного игрового профиля в приложении нет.

Локальный прогресс удаляется через настройки Android → приложения → «Двор 48: Вытащи тачку» → хранилище → очистка данных. При удалении приложения прогресс может быть утрачен.
